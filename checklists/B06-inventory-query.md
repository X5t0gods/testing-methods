# B06 · 库存查询与流水

主要风险：筛选分页、预警与导出。

本页是测试设计清单，不是通过报告。前置：明确业务规则、源码版本、测试数据与隔离环境。

| 场景 | 方法与输入 | 必须观察的结果 |
| --- | --- | --- |
| 普通分页与状态计算筛选 | 同数据覆盖两种路径及分页边界 | 总数、筛选口径和每页结果正确且无重复遗漏 |
| 安全库存、临期与零数量 | 检查等于阈值、前后一天与零值 | 预警边界与业务定义一致 |
| 库存明细、流水与导出 | 比较界面/接口/文件的数据范围与精度 | 数量可勾稽，列、单位和时间口径一致 |

## 交付与结束条件

记录实际执行项、命令或操作、退出码/请求结果与必要的脱敏证据。发现缺陷后补充最小复现、修复前失败、修复后通过及相关回归；未运行、跳过和不具备条件的项分别列出。

检查操作后的持久化状态、关联记录和测试数据清理。涉及真实接口的前端场景还应核对 HTTP 状态、业务码及刷新后的结果。
