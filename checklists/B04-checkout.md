# B04 · 收银主链路结算

主要风险：金额、幂等与库存事务。

本页是测试设计清单，不是通过报告。前置：明确业务规则、源码版本、测试数据与隔离环境。

| 场景 | 方法与输入 | 必须观察的结果 |
| --- | --- | --- |
| 扫码、试算、促销、支付与结算 | 设计能手算的购物篮并逐阶段核对 | 金额链路一致，支付与订单状态正确 |
| 半分、零库存、刚好库存和超额请求 | 边界值与精确十进制对照 | 舍入按业务口径，数量和金额不越界 |
| 重复请求、并发扣减与中途异常 | 同请求标识重放、并行请求及故障注入 | 效果仅一次，库存/流水/付款记录保持一致 |

## 交付与结束条件

记录实际执行项、命令或操作、退出码/请求结果与必要的脱敏证据。发现缺陷后补充最小复现、修复前失败、修复后通过及相关回归；未运行、跳过和不具备条件的项分别列出。

检查操作后的持久化状态、关联记录和测试数据清理。涉及真实接口的前端场景还应核对 HTTP 状态、业务码及刷新后的结果。
