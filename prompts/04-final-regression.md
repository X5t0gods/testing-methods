# 收尾回归提示词

```text
任务：完成 {{轮次}} 的收尾验证与汇总，不在本轮追加业务修复。

基线：{{证据与源码快照}}
当前版本：{{源码快照与未提交改动}}
允许命令及环境：{{清单}}
本轮缺陷与模块报告：{{索引}}

要求：
1. 跑已授权的测试、静态检查和必要流程；保留退出码与关键输出。
2. 确认前后范围、数据、配置可比较；不可比较的指标只并列，不计算改善。
3. 分开报告相关子集、全量、跳过与未执行，避免重复计数。
4. 汇总已修、已确认未修、候选风险和环境限制。
5. 检查业务数据残留与测试环境清理。
6. 只对实际执行的范围下结论，不能说“系统零缺陷”。

输出：前后对照表、缺陷回归表、未验证清单、证据索引与发布建议。
```
