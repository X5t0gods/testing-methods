# 公开范围与隐私处理

本仓库按照面向招聘评估的公开作品集整理。公开内容是方法、模拟示例、模块测试设计与脱敏结果摘要。

## 1. 本次公开的材料

- 根据现有工作流重写的方法说明与阶段提示词。
- 15 个后端、12 个前端模块的通用测试清单。
- 从项目记录中筛选的历史统计、适用范围与限制。
- 使用模拟输入重新编写的两个独立回归示例。
- 来源文件的 SHA-256 与必要统计摘录，用于后续核对。

## 2. 未公开的材料

账号密码、认证令牌、连接串、内网地址、个人联系方式、本机用户目录、真实会员或订单数据、数据库备份、完整日志、聊天记录、开发工具缓存及业务项目完整源码。

演示账号的默认密码同样不进入公开材料。例子使用模拟标识与数值；“可复现”指示例可运行，不表示真实环境凭据随仓库提供。

## 3. 对历史材料的处理方式

原工作区文件保持原状。本库没有整包复制原提示词或原日志，而是提取方法并重新编排，避免把历史待核实结论、局部环境限制和敏感信息一起公开。

原文中的固定电脑路径、示例登录信息与不可控的批量回滚命令未被沿用。旧覆盖率、测试数量与性能值均在效果页中注明来源和历史属性。

## 4. 更新时继续检查的范围

检查新增正文、示例、JSON、附件、截图、文件名、Git diff 与 Release 正文。不要只检查当前页面而忽略 Git 历史；敏感文件应在第一次提交前排除。

`tools/verify_docs.py` 包含常见凭据格式和本机路径的辅助检查，但它不是完整的秘密扫描或隐私审计。公开前仍要阅读实际变更内容。
