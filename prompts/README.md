# 分阶段测试提示词

这些提示词根据既有实践重新编排，采用通用占位符，不包含原项目登录资料、本机路径或历史缺陷断言。先填目标、环境和授权边界，再提交任务。

| 顺序 | 提示词 | 交付 |
| --- | --- | --- |
| 1 | [基线检查](01-baseline.md) | 当前失败、覆盖范围、环境与数据限制 |
| 2 | [模块定位与用例设计](02-module-analysis.md) | 候选风险、业务依据与最小复现方案 |
| 3 | [修复与回归闭环](03-fix-and-regress.md) | 修复前失败、最小修复、修复后通过与回归 |
| 4 | [收尾回归](04-final-regression.md) | 同口径前后结果、遗留与未验证 |
| 专项 | [需求证据核查](05-requirement-audit.md) | 需求—实现—验证证据映射 |

提示词是协作工具，不能替代业务判断。已经得到授权且条件明确时可以连续完成阶段；涉及新权限、业务争议或明显范围扩展时再请求具体判断。
