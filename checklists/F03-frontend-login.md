# F03 · 登录与布局

主要风险：登录跳转和权限展示。

本页是测试设计清单，不是通过报告。前置：明确业务规则、源码版本、测试数据与隔离环境。

| 场景 | 方法与输入 | 必须观察的结果 |
| --- | --- | --- |
| 验证码、错误登录和重复点击 | 覆盖过期、刷新及加载期间操作 | 提示正确，不重复提交或复用过期状态 |
| 登录后回跳与页面刷新 | 不同来源路径和登录态测试 | 回到允许页面，不产生循环跳转 |
| 菜单、按钮与直接地址访问 | 切换角色并访问受限路径 | 界面过滤与后端鉴权一致 |

## 交付与结束条件

记录实际执行项、命令或操作、退出码/请求结果与必要的脱敏证据。发现缺陷后补充最小复现、修复前失败、修复后通过及相关回归；未运行、跳过和不具备条件的项分别列出。

检查操作后的持久化状态、关联记录和测试数据清理。涉及真实接口的前端场景还应核对 HTTP 状态、业务码及刷新后的结果。

使用[模块报告模板](../templates/module-report.md)记录结果，返回[清单索引](README.md)。
