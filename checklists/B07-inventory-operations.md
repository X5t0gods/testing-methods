# B07 · 盘点、报损与调拨

主要风险：库存变化的原子性。

本页是测试设计清单，不是通过报告。前置：明确业务规则、源码版本、测试数据与隔离环境。

| 场景 | 方法与输入 | 必须观察的结果 |
| --- | --- | --- |
| 盘点快照与差异调整 | 快照后发生交易，再按业务规则提交差异 | 不以旧快照覆盖期间合法变化 |
| 报损/调拨的草稿、审核、取消 | 覆盖合法迁移、重复提交与非法状态 | 库存只在约定节点变化且效果一次 |
| 多门店调拨与中途失败 | 核对两端库存与流水并注入失败 | 一增一减守恒，失败没有单边变化 |

## 交付与结束条件

记录实际执行项、命令或操作、退出码/请求结果与必要的脱敏证据。发现缺陷后补充最小复现、修复前失败、修复后通过及相关回归；未运行、跳过和不具备条件的项分别列出。

检查操作后的持久化状态、关联记录和测试数据清理。涉及真实接口的前端场景还应核对 HTTP 状态、业务码及刷新后的结果。
