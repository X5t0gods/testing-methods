# 需求证据核查提示词

```text
任务：核查下列需求在指定版本中的实现与验证证据。本阶段仅检查材料。

需求清单：{{可判定的条目}}
允许读取的源码/测试/报告：{{文件清单}}
禁止操作：修改文件、启动服务、运行测试和超范围检索。

要求：
1. 需求文档描述目标，不能单凭文档判定已实现。
2. 源码证据说明存在实现；运行证据才说明对应路径已执行。
3. 未找到、未实现、部分实现、实现但未验证要区分。
4. 每个判断给文件位置与必要的短引用，不输出完整私有代码。
5. 历史证据注明版本与日期，不能自动用于当前版本。

输出：
需求 | 实现判定 | 源码证据 | 验证证据 | 缺口/限制
```
