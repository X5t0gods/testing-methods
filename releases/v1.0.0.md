# v1.0.0 · 软件测试实践作品集

首次发布面向招聘评估的公开测试方法库，整理社区超市管理系统中的测试设计、缺陷回归与效果证据。

- 风险驱动测试、分层验证、边界值、状态迁移、幂等并发与数据不变量。
- 15 个后端、12 个前端模块的测试清单。
- 金额舍入与多门店汇总两个独立回归示例，可观察旧实现失败与修复后通过。
- 报表专项的历史结果：相关测试 109 passed、当时全量 772 passed；两个目标文件的语句与分支覆盖率 100%。
- 公开来源指纹与必要摘要，保留历史性能未达标项和复现限制。
- 提供报告模板、阶段提示词、文档校验与后续同仓库版本维护约定。

本次发布验证文档库和独立示例，没有重跑私有业务项目。历史测试与性能数字不代表当前项目状态，原始源码、凭据、业务数据、日志和聊天记录未公开。

发布校验：文档链接、版本与证据结构检查通过；两个 before 示例因预期业务断言失败而返回 1，两个 after 示例全部通过并返回 0。详见[独立示例](../examples/README.md)及[实际验证摘要](../evidence/portfolio-validation.json)。
